# Publication notes

Generative Night / Pointillism is being preserved as a public-source candidate.

Current scope: Interactive p5.js painting and image-to-dots pages; small enough to present as a focused creative-coding project.

Preparation still required: Combine the useful variants into one project, add a README, screenshots, controls and license. Document the external p5.js dependency and use sample images you can share.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.
